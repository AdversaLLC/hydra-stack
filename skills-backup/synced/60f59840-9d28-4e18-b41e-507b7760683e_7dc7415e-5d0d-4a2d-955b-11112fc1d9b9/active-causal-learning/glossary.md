# Glossary

- **Batch-intervention design** — manipulate all variables of a sufficient set at once; optimal = smallest such set (ch04).
- **Chain component** — node set connected by undirected edges after removing directed edges (ch02).
- **Chain graph** — graph with directed and undirected edges and no partially directed cycle (ch02).
- **Chordal graph** — every cycle of length ≥ 4 has a chord (ch02).
- **e(V)** — orientation of edges determined by manipulating V (ch03).
- **Essential graph G*** — same skeleton as G; an edge is directed iff it has that direction in every DAG of [G] (ch02).
- **Faithfulness** — every conditional independence in P is entailed by the Markov property (ch02).
- **Legal combination of orientations** — orientations that create no v-structure, no cycle, and no conflicting edge direction (ch04).
- **Markov equivalence class [G]** — DAGs encoding the same conditional independences (ch02).
- **Maximum-entropy criterion** — choose V maximizing H_V = −Σ (l_i/L) log(l_i/L) (ch04).
- **Minimax criterion** — choose V minimizing the largest resulting subclass (ch04).
- **Minimum sufficient set** — sufficient set with no sufficient proper subset (ch04).
- **PC algorithm** — constraint-based structure learner used to get the essential graph (ch05).
- **Quasi-experiment** — intervention that changes P(vi | pa(vi)) without cutting Vi from its parents (ch03).
- **Randomized experiment** — intervention that assigns Vi at random, cutting it from pa(Vi) (ch03).
- **Sequential-intervention design** — choose each next manipulation after seeing previous results (ch04).
- **Sufficient set** — manipulated variables that orient every undirected edge whatever the true DAG (ch04).
- **v-structure** — Vi → Vk ← Vj with Vi, Vj non-adjacent (ch02).
