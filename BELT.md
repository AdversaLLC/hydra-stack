# BELT — every skill in the stack, its tier, and where it loads

Generated by `hydra_graph.py belt --write` from the SKILL.md files on disk. 102 skills: 25 installed (their descriptions cost ~4,284 tokens in every session) and 77 shelved (on disk, zero per-session cost, `belt --load <name>` installs one). 949,227 bytes of SKILL.md in all, ~237,301 tokens if every body were loaded at once. Per phase, `belt --phase <slot>` lists only that slot's skills, descriptions only (never bodies).

Slots: start, discuss, plan, execute, verify, ship, learn, ops, gate, consult, tool, memory. A skill with no rule is placed by keyword; `unplaced` is reported by doctor and left for hydra-evolve to place.

- **hydra-belt**: the router: ~1 KB, the only always-on belt text
- **hydra-consult**: auto second opinion at loop points; routes to call-a-friend
- **hydra-evolve**: ABSORB on every new skill/repo; CONDENSE every 3rd absorb
- **hydra-graph**: graph context at start; recall before fan-out; ship-tail at Ship
- **hydra-mem**: raw capture via hooks; lookups via search -> timeline -> get
- **hydra-swarm**: Prime/Hub/Leaf waves; graph contract + admission control (absorbed 2026-10-21)
- **karpathy-guidelines**: surface assumptions in Plan; surgical changes + goal-driven loop in Execute. Overlaps CLAUDE.md 'keep diffs to the task' - one home: CLAUDE.md states the rule, this skill carries the checklist
- **modulated-loop-orchestrator**: Phase 0 router + fan-out in Discuss; Build Track gate in Plan; Baseline Check + critique in Verify
- **napkin**: read .claude/napkin.md at start as a failed_path source
- **razor**: scope discipline; declined cuts -> FAILED PATHS
- **research-verification**: before any number/claim/count is written
- **schematic**: brownfield only: branch diff -> spec before Specify
- **setup-audit**: ops: after install and when sessions get expensive; plan: agent-readiness check on a new repo (/gsd-onboard); learn: repeated-mistake findings feed nested-learning RETRO
- **theorist**: theory-keeper defers to it when installed (THEORY.MD home)
- **veritas**: every upload audited before work starts
- **wisdom-memory**: Tier 2 is now hydra-graph; Tier 3 (claude.ai) unchanged
- **accessibility-review**: UI/UX domain: WCAG 2.1 AA pass beside the done-gate
- **brainstorming**: superpowers; spine-level - use when GSD is not the spine (claude.ai native loop)
- **context-compact**: harvest a long session into the graph at checkpoints
- **design-critique**: UI/UX domain: critique the mockup before Plan
- **design-handoff**: UI/UX domain: spec sheet is the Ship artifact for designs
- **design-system**: UI/UX domain: tokens/components consistency gate in Plan
